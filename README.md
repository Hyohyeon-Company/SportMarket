# SportMarket

운동 장비(홈짐·덤벨·플레이트) 특화 C2C 중고거래 플랫폼의 모노레포입니다.

- `apps/web` — React 웹 클라이언트
- `apps/api` — NestJS API 서버
- `packages/shared` — 공유 타입·계약
- `docs/engineering.md` — 엔지니어링 기준

## 상태

초기 모노레포 스캐폴드 단계입니다. 승인된 API 계약은 팀의 비공개 제어 워크스페이스에 핀되어 있으며, 구현은 이 저장소의 Issue → 짧은 브랜치 → PR 흐름으로 진행합니다. 앱 실행·CI·배포는 서버 바인딩 이후에 활성화합니다.

## 기여

`AGENTS.md`와 `docs/engineering.md`를 읽고, 도메인 Issue와 리뷰 가능한 PR을 사용하세요. 비공개 대화·자격증명·운영 데이터는 커밋하지 않습니다.
